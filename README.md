# NEXSTAY

The operating system for India's PG (paying guest) industry — a PG management ERP, a tenant living app, and a PG marketplace on one platform.

Development has not started yet; this repo currently holds the product documentation.

## Documentation

- [docs/PRD.md](docs/PRD.md) — product requirements: personas, journeys, functional requirements with acceptance criteria, data model, release scope, assumptions and open questions.
- [docs/ROADMAP.md](docs/ROADMAP.md) — requirements summary, proposed architecture, data model, and phased build plan.
- [docs/source-documents/](docs/source-documents/) — original business plan, overview and pitch deck, plus extracted text.

## Products

| Product | User | Purpose |
| --- | --- | --- |
| PG Management ERP | PG owner and staff | Rooms, tenants, rent, expenses, complaints, employees, invoices, analytics |
| PG Marketplace | Prospective tenant | Discovery, reels feed, transparent pricing, AI matching, booking enquiry |
| Tenant App | Resident tenant | Rent, invoices, complaints, agreements, notices |
